# 資産リバランスツール

シンプルでわかりやすい資産配分計算ツールです。ブラウザで動作するため、環境構築不要。どのPCからでもすぐに使用できます。

## 特徴

- **インストール不要** - HTMLファイルをブラウザで開くだけ
- **オフライン対応** - ローカルで完全に動作
- **直感的UI** - シンプルで使いやすいインターフェース
- **リアルタイム計算** - 入力するとすぐに結果を表示
- **口数計算** - 投資信託の基準価額から必要な口数を自動計算
- **ビジュアル表示** - 現在の配分と目標配分をチャートで比較

## 機能

### 入力項目
- **現在の資産配分** - 各資産の現在の保有金額
- **目標資産配分** - 各資産の目標比率（%）
- **投資信託の基準価額** - 全世界株インデックスファンド、日経平均インデックスファンドの基準価額

### 資産クラス
- 全世界株インデックスファンド
- 日経平均インデックスファンド
- 日本株
- 米国株
- ビットコイン
- イーサリアム
- ソラナ
- 現金

### リバランス提案
提案結果には以下の情報が表示されます：
- 必要な買い増し/売却金額
- 基準価額が設定されている投資信託の場合、買い増し/売却に必要な口数
- 配分比率の変化（ポイント）
- 現在の配分と目標配分の差異をビジュアル表示

## 使い方

1. **ファイルを開く**
   - `asset-rebalancer.html` をダウンロード
   - ブラウザにドラッグ&ドロップするか、ダブルクリック

2. **現在の資産を入力**
   - 左側の「現在の資産配分」に各資産の金額を入力
   - リアルタイムで合計金額が表示されます

3. **CSVから現在の資産を取り込む（オプション）**
   - 「現在の資産配分」セクションのファイル選択でCSVファイルを選び、「CSV取込」をクリック
   - CSVのヘッダー行から、銘柄名・商品名・通貨名の列と、評価額・時価評価額・残高の列を自動で探します
   - 取り込み後は資産クラスごとの合計額が既存の入力欄に反映され、総資産表示も更新されます
   - 分類できなかった行は画面上に警告として表示されるため、該当する資産クラスへ手入力で補正してください

4. **目標配分を設定**
   - 右側の「目標資産配分」に各資産の目標比率を入力
   - 合計が100%になるように調整してください

5. **基準価額を入力（オプション）**
   - 投資信託を購入/売却予定の場合、基準価額を入力
   - 入力すると、購入/売却に必要な口数が表示されます

6. **計算実行**
   - 「リバランス提案を計算」ボタンをクリック
   - チャートとリバランス提案が表示されます

### CSVアップロード

CSVファイルは、カンマ区切り・ダブルクォート囲み・改行を含む一般的なCSV形式に対応しています。外部ライブラリを使わず、ブラウザ内でローカルに読み込むため、CSVの内容はサーバーへ送信されません。

#### 対応列名

以下の候補列名をヘッダー行から探索します。証券会社・取引所によって列名が異なる場合は、CSVのヘッダー名をいずれかに合わせてください。

- **銘柄名・商品名・通貨名**: `銘柄`, `銘柄名`, `商品名`, `通貨`, `Symbol`, `Asset`
- **評価額・時価評価額・残高**: `評価額`, `時価評価額`, `評価金額`, `円換算額`, `残高`, `Amount`, `Value`

#### 分類ルール

銘柄名・商品名・通貨名に含まれる文字列から、以下の資産クラスへ分類します。

| 含まれる文字列 | 分類先 |
| --- | --- |
| `オルカン`, `全世界`, `ACWI` | 全世界株インデックスファンド |
| `日経`, `Nikkei`, `225` | 日経平均インデックスファンド |
| `日本株`, `国内株` | 日本株 |
| `米国株`, `US`, `S&P500`, `NASDAQ` | 米国株 |
| `BTC`, `Bitcoin`, `ビットコイン` | ビットコイン |
| `ETH`, `Ethereum`, `イーサリアム` | イーサリアム |
| `SOL`, `Solana`, `ソラナ` | ソラナ |
| `現金`, `JPY`, `日本円` | 現金 |

#### 未分類行の扱い

分類ルールに一致しない行、銘柄名が空欄の行、評価額を数値化できない行は取り込み結果の警告欄に表示されます。警告を確認し、必要に応じて既存の入力欄へ手入力で補正してください。

## 結果の見方

### リバランス提案

**例：売却の場合**
```
¥81,600
(2331口売却)
(-1.5ポイント)
```

**例：購入の場合**
```
¥29,600
(3947口購入)
(+0.6ポイント)
```

- **金額** - 買い増し/売却する金額
- **口数** - 基準価額が設定されている投資信託のみ表示
- **ポイント** - 配分比率の変化

## 技術仕様

### 口数の計算方法

投資信託の基準価額は「10,000口当たりの価格」を意味しています。

```
必要な口数 = (金額 × 10,000) ÷ 基準価額
```

**例：**
- 基準価額：100,000円（10,000口当たり）
- 買い増し金額：50,000円
- 必要な口数：(50,000 × 10,000) ÷ 100,000 = **5,000口**
